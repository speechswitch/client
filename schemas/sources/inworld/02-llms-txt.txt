# Inworld AI

> Inworld AI provides APIs for building voice AI applications: Realtime TTS (text-to-speech), Realtime STT (speech-to-text), Realtime speech-to-speech, and Realtime Router for LLM routing across providers.

- Base URL: `https://api.inworld.ai`
- Authentication: API key via `Authorization: Basic <base64(apiKey:)>` header. Get your key at [platform.inworld.ai](https://platform.inworld.ai).
- All endpoints accept and return JSON unless otherwise noted. Audio endpoints return binary (MP3, PCM, WAV, Opus, mu-law, A-law).
- For full content of all documentation pages, see [llms-full.txt](https://docs.inworld.ai/llms-full.txt).

## Realtime Text-to-Speech (TTS)

Models: `inworld-tts-2` (flagship and production default — best quality, latency, and concurrency; 200+ languages and locales, steering, ~120ms P50), `inworld-tts-1.5-max` (15 languages, <200ms P50, maximum stability), `inworld-tts-1.5-mini` (cheapest per character, tuned for English — use TTS-2 for other languages). TTS-2 uses `delivery_mode` (STABLE, BALANCED, EXPRESSIVE) instead of `temperature`.

- [Intro to TTS](https://docs.inworld.ai/tts/tts.md): Overview of Realtime TTS — three models (TTS-2, 1.5 Max, 1.5 Mini) with feature comparison covering latency, voice cloning, steering, and multilingual support
- [TTS Models](https://docs.inworld.ai/tts/tts-models.md): Full model lineup with model IDs, language counts, and latency
- [Generating Audio](https://docs.inworld.ai/tts/capabilities/generating-audio.md): Voices, audio formats (MP3, PCM, WAV, Opus, mu-law, A-law), delivery mode (TTS-2), temperature (TTS-1.5), and language selection
- [Steering](https://docs.inworld.ai/tts/capabilities/steering.md): Direct TTS-2 voice performance with natural-language instructions in square brackets — emotion, articulation, volume, pitch, speed, vocal style, and non-verbals ([laugh], [sigh], etc.)
- [Language Support](https://docs.inworld.ai/tts/capabilities/multilingual.md): TTS-2 supports 200+ languages and locales in two tiers (Tier 1: 15 most extensively evaluated; Tier 2: fully supported, results can vary more) plus cross-lingual synthesis
- [Synthesize Speech](https://docs.inworld.ai/tts/synthesize-speech.md): Send text to the TTS REST API and receive a complete audio file in one response
- [Streaming Synthesis](https://docs.inworld.ai/tts/synthesize-speech-streaming.md): Stream TTS audio chunks over HTTP for low-latency playback as they are generated
- [WebSocket Synthesis](https://docs.inworld.ai/tts/synthesize-speech-websocket.md): Stream TTS over WebSocket for lowest-latency, bidirectional audio generation
- [Instant Voice Cloning](https://docs.inworld.ai/tts/instant-voice-cloning.md): Clone any voice from an audio sample (as little as 5 seconds) using the Inworld API
- [Professional Voice Cloning](https://docs.inworld.ai/tts/professional-voice-cloning.md): Fine-tune a highly similar, stable voice clone from a larger set of audio samples (Beta)
- [Voice Design](https://docs.inworld.ai/tts/voice-design.md): Generate a custom voice from a text prompt describing the desired vocal style
- [Voice Sharing](https://docs.inworld.ai/tts/voice-sharing.md): Publish custom voices to the community Voice Library and discover voices shared by others
- [Voice Tags](https://docs.inworld.ai/tts/capabilities/voice-tags.md): Filter and search voices by metadata tags like gender, accent, and age
- [Pause Controls](https://docs.inworld.ai/tts/capabilities/pause-controls.md): Add pauses to TTS output with SSML break tags
- [Custom Pronunciation](https://docs.inworld.ai/tts/capabilities/custom-pronunciation.md): Control word pronunciation with inline IPA phoneme notation in TTS input
- [Verbatim Tags](https://docs.inworld.ai/tts/capabilities/verbatim.md): Force literal, character-by-character reading of codes, IDs, and other exact strings
- [Timestamps](https://docs.inworld.ai/tts/capabilities/timestamps.md): Get word- and character-level timing data from TTS for captions and lipsync
- [Python SDK](https://docs.inworld.ai/tts/python-sdk.md): Use the `inworld-tts` package for synthesis, voice cloning, and voice design in Python
- [Node.js SDK](https://docs.inworld.ai/tts/node-sdk.md): Use the `@inworld/tts` package for synthesis, voice cloning, and voice design in Node.js
- [Integrations](https://docs.inworld.ai/tts/integrations.md): Use Realtime TTS with LiveKit, Twilio, Pipecat, and other voice platforms
- [Telephony (Twilio)](https://docs.inworld.ai/tts/telephony-twilio.md): Power phone calls with Realtime TTS using Twilio ConversationRelay and the LLM + TTS Router feature
